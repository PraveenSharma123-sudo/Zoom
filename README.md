# 🎥 Zoom Clone - MERN Stack

A full-stack video conferencing web application built using the MERN Stack (MongoDB, Express.js, React.js, Node.js). This project allows users to create and join virtual meetings with real-time video/audio communication, chat functionality, and secure authentication.

---

# 🚀 Features

- 🎥 Real-Time Video Calling
- 🎙️ Audio Communication
- 💬 Live Chat Messaging
- 🔐 User Authentication & Authorization
- 📅 Create & Join Meeting Rooms
- 🧑‍🤝‍🧑 Multiple Participants Support
- 📱 Fully Responsive Design
- ⚡ Real-Time Communication using Socket.io / WebRTC
- 🖥️ Screen Sharing Feature
- 📹 Camera & Microphone Controls

# ⚙️ Installation

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/Zoom-Clone-MERN.git
```

## 2️⃣ Navigate to Project Folder

```bash
cd Zoom-Clone-MERN
```

---

# 📦 Install Dependencies

## Backend Dependencies

```bash
cd server
npm install
```

## Frontend Dependencies

```bash
cd client
npm install
```

---

# 🔑 Environment Variables

Create a `.env` file inside the `server` folder:

```env
PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
CLIENT_URL=http://localhost:3000
```

---

# ▶️ Run the Project

## Start Backend Server

```bash
cd server
npm start
```

## Start Frontend

```bash
cd client
npm start
```
